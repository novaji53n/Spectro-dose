1 · เชื่อมต่อเครื่อง

พอร์ต (COM)

เบราว์เซอร์ไม่แสดงเลข COM ของ Windows — จะแสดงเป็นลำดับพร้อมรุ่นชิป USB · เลือกผิดให้ตัดการเชื่อมต่อแล้วเลือกใหม่

ใช้ Chrome หรือ Edge เท่านั้น · เปิดไฟล์ตรง ๆ หรือผ่าน http://localhost ก็ได้ · ค่าเริ่มต้น 9600 8-N-1 ปรับให้ตรงกับเครื่อง

ให้เครื่องส่งค่าออกมา ต้องกดอะไร
  1. Utility → Printer setup → Change → เลือก Serial → Accept
    ถ้าเป็น OFF / Internal / Parallel ค่าจะไม่ถูกส่งออกพอร์ต RS-232
  2. Utility → RS232 → ตั้ง baud ให้ตรงกับช่องด้านบน (ปกติ 9600, 8, none, 1) → Accept
  3. กลับไปโหมดวัด (A/T/C) แล้วกด Print หนึ่งครั้ง = ส่งค่าที่ค้างบนจอ 1 ค่า

2 · สั่งอ่านค่าจากคอมพิวเตอร์

รุ่นนี้รับคำสั่ง SND แล้วจะส่งค่าอ่านกลับมาทันที (9600 8-N-1) — ไม่ต้องกด Print ที่เครื่อง · เปิด “ส่งซ้ำอัตโนมัติ” เพื่ออ่านต่อเนื่อง

ข้อมูลดิบจากพอร์ต (ใช้หา baud / รูปแบบ)
